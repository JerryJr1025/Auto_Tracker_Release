# Auto Tracker Linux 0.0.6 Alpha

First-time test release.

1. Download `Auto_Tracker_Linux_0.0.6_Alpha.zip`.
2. Extract the entire ZIP.
3. Keep `Auto_Tracker.sh` and `Auto_Tracker.bat` together; the current Linux launcher depends on the BAT file.
4. Ensure Node.js, npm, and Python 3 are installed.
5. Run `chmod +x Auto_Tracker.sh` and then `./Auto_Tracker.sh`.
